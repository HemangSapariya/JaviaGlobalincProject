# Javia Global Inc. React Website

Converted from the supplied static HTML website into a React + Vite project.

## Open in Visual Studio Code

1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open Terminal in VS Code.
4. Run:

```bash
npm install
npm run dev
```

Vite will show a local URL such as `http://localhost:5173`.

## Production build

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## Main files

- `src/App.jsx` - React components and website sections
- `src/products.js` - product catalogue data
- `src/styles.css` - full website styling
- `public/products/` - product images
